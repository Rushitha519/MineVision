# MineVision 

## Safe and Efficient Operation of Mine Vehicles in Fog and Low-Visibility Conditions

MineVision is a retrofit-friendly safety system designed for mining dumpers operating in fog and low-visibility conditions.

The system detects obstacles and low-visibility conditions and provides warnings to the driver. It also uses Vehicle-to-Vehicle (V2V) communication to broadcast warnings to nearby dumpers.

## Core Workflow

SENSE → PROCESS → ALERT → BROADCAST

## Hardware

- ESP32
- HC-SR04 Ultrasonic Sensor
- IR Obstacle Sensor
- LDR
- NRF24L01
- LCD
- Buzzer
- LED
- Motor Driver
- DC Gear Motors

## Main Features

- Obstacle detection
- Low-visibility estimation
- Driver warning
- V2V warning communication
- Retrofit-friendly design
- Low-cost prototype
